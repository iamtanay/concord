# Logging Standard 2026

## 1 Purpose

This standard defines how Northwind Analytics collects and stores operational logs.

## 2 Collection

All services send application logs to the central log platform. Logs are structured as JSON.

## 3 Retention

Application logs are kept for 30 days. Security audit logs are kept for one year.

## 4 Access

Access to the log platform is role-based. Multi-factor authentication is optional for log platform users.
